# Kit ChatGPT + Grok : épisode 1 de Villa Vitamine dans le nouveau rendu

1. **ChatGPT** fait l'**image** de chaque plan. Joins les images de référence indiquées (dossier
   `personnages/references_nouveau_style/`) et colle le prompt « Image ».
2. **Grok** fait l'**animation**. Importe l'image de ChatGPT et colle le prompt « Animation ».
3. **Envoie-moi** l'image et la vidéo de chaque plan ici, avec le numéro du plan. Je vérifie que les personnages
   ressemblent aux références, puis je monte l'épisode (couverture, accroche, noms, sous-titres, musique).

Si Grok ne fait pas parler les personnages en français, ce n'est pas grave : j'ajoute les voix au montage.

animation film still, vibrant saturated colors, warm golden-hour light, humanoid fruit characters with human bodies,
exactly the same characters as the attached reference images, reality-TV parody, no text.*
