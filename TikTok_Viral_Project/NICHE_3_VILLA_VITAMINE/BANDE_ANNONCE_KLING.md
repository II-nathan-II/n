# Bande-annonce Villa Vitamine — à générer sur le site Kling

Les 66 crédits gratuits du compte Kling ne sont utilisables que sur le site ou l'appli Kling, pas par le connecteur. Cette bande-annonce de 28 s (5 plans de 5 s) est conçue pour eux : elle sert à tester la réaction du public avant de produire la saison.

## Réglages sur kling.ai

1. **Vidéo → Texte vers vidéo**, modèle **Kling 3.0** (ou le plus récent qui gère le son).
2. Format **9:16**, durée **5 s**, qualité standard (720p), **son / audio natif activé**.
3. Regarde le coût affiché sur le bouton « Générer » avant de lancer. Si les 66 crédits ne suffisent pas pour les 5 plans, fais-les dans cet ordre : **5, 2, 3, 4, 1** (le plan 1, la villa vue du ciel, est le moins indispensable).
4. Télécharge chaque vidéo **sans filigrane** si l'option est proposée, et renomme-la `01.mp4` … `05.mp4` selon le numéro du plan.
